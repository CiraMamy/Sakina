# Sakina Packages

This directory will contain shared libraries and abstractions used across the monorepo.

Suggested packages:

- `domain/`
- `contracts/`
- `database/`
- `security/`
- `crypto/`
- `ai-client/`
- `observability/`
- `config/`
- `fhir/`
- `testing/`

The purpose is to preserve domain clarity and enable future extraction without a rewrite.
